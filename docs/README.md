# Agrijuune Documentation Pack

This pack contains the eight project instruction and engineering
reference files.

Start with `AGENTS.md`. It directs the coding agent to consult the other
documents before making changes.

## Files

-   `AGENTS.md` --- agent operating instructions
-   `MASTER.md` --- product purpose, scope and approved baseline
-   `ARCHITECTURE.md` --- application boundaries and request flow
-   `CODING_STANDARDS.md` --- code quality and SOLID principles
-   `SECURITY.md` --- security and privacy requirements
-   `DATABASE.md` --- Supabase schema and access baseline
-   `API_CONTRACTS.md` --- first-release API contract
-   `TESTING.md` --- verification strategy

## Important status notes

These documents are based on the current Agrijuune first-release scope:
public website, standard sample demo and enquiry capture. They
deliberately do not specify a full farm-management application.

TypeScript, styling framework, package manager, hosting, email provider,
final form fields, privacy notice and retention period remain decisions
to confirm. Review all proposed schema and SQL before applying it to a
database.
