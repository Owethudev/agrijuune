## 10. Data Retention

Agrijuune will retain personal information only for as long as reasonably necessary to fulfil the purpose for which it was collected, unless a longer period is required or permitted by law.

For website enquiries, the product owner has set a seven-day retention period for database records, starting when the enquiry is submitted. Each party will retain their email copies as communication records. A daily production purge is configured for 02:00 GMT and deletes records older than seven days; because it runs daily, deletion may occur up to 24 hours after a record crosses the seven-day cutoff. The Supabase schedule is active, but its first successful execution has not yet been verified. The production enquiry table contained no records when the schedule was configured. The Supabase dashboard was checked on 2026-11-25 and shows that both production and staging use the Free Plan, which does not include project backups; the seven-day backup-retention target is not met. Collection must remain disabled until a successful purge execution is verified, adequate backup retention is available, and provider details are confirmed. Brevo message and log retention remains to be confirmed.

When personal information is no longer required, it will be securely deleted, destroyed or de-identified where appropriate.
